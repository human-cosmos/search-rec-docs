## 01 产品范围

万镜魔方是当前原型的界面名称，对话问候使用「乘风智能体」。产品历史版本沿用原编号。

- **当前原型**使用浏览器状态、本地样例资源和计时器演示流程。文件上传、播放器、文本复制和跟品 ZIP 导出有本地交互。检索、商品克隆、媒体生成、投放指标与优化效果使用演示数据。
- **Q4 规划**沿用 v1.4 的工程目标。内测范围为 1–2 个市场、1–2 个品类、每个品类头部 50–100 条视频、5–10 名优化师。检索时延、并发、真实加工、权限和素材回流见第 16–17 节。
- **范围边界**为轻量二创与裁剪。完整长片从零生成、重型剪辑器、混剪、数字人、真实落地页生产和直接投放仍在本期范围之外。技能菜单可演示单点能力，技能市场另行确认。

### Q4 产品目标

| 编号 | 目标 | 验收方向 |
| --- | --- | --- |
| G1 | 在同一工作区完成找片、替换与合成 | 内测优化师走完主路径 |
| G2 | 打开成片即可查看槽位、口播和提示词 | 试点素材完成预加工 |
| G3 | 生成、合成与浏览可并行 | 耗时任务提交后仍可继续操作，结果可找回 |
| G4 | 产出归个人后按规则回流 | 校验保护期与可见范围 |
| G5 | 行为数据反哺推荐与产品改进 | 形成使用漏斗、偏好与片段供给指标 |

旧规划将工作量估算为基础素材库与生成 40%、搜索与调度 30%、槽位二创 30%。

| 名词 | 定义 |
| --- | --- |
| 成片 | 可播放的完整广告视频，样例可关联商品、线路及投放指标。 |
| 槽位 | 成片的有序时间区间。数据存在时可展示镜头、提示词、口播及指标。 |
| 片段 | 可独立打开或作为替换参考的镜头，具备独立视频或可引用的源视频时间区间。 |
| 二创 | 在已有成片上换镜头或调整槽位顺序，按当前顺序合成。 |
| 爆款复刻 | 以参考视频为起点整片重做，可配置产品、人物和场景。 |
| 做同款 | 在支持的结果卡或视频入口沿用参考结构做一个版本，具体控件随入口变化。 |

## 03 信息架构与模块边界

首页由输入区、智能体快捷入口、爆单 Hook 镜头、「潜在爆品」和广告视频库组成。会话负责发起任务和查看回复，右侧工作区负责选片、画布操作或落地页对照。侧栏提供会话、我的跟品、资产、收藏、技能等入口。

找片、跟品广告素材共用视频交互与槽位结果布局。跟品「落地页」采用按页面顺序排列的原版与当前版对照。「广告素材」使用 tldraw 画布。会话、跟品任务、偏好和上传文件的持久化口径见第 12 节。

## 04 找片、二创与爆款复刻

1. 输入文字、产品 ID 或参考素材，也可从「找爆款」「视频二创」「爆款复刻」案例进入。
2. 找片先在对话解析条件，按对应入口展示确认或本地结果。结果消息提供数量、缩略图与查看全部入口。
3. 点缩略图打开对应视频，点「…」进入完整结果画布。带可用槽位的成片可选时间轴镜头，槽位操作见第 7 节。
4. 视频二创进入带槽位的成片，可继续定位、替换、重排或合成。画布中的动作和结果保留在当前会话。
5. 首页爆款复刻在对话中选参考片、确认复刻方案并展示原生播放器结果。有参考视频时可直接进入方案。复刻参数与参考图校验见第 7 节。

## 全链路跟品

### 入口与参数

首页「全链路跟品」提供三套案例。「潜在爆品」卡带入商品。也可输入商品 ID、链接或样例名称。首页提交含商品输入、可识别目标国家与平台时直接开始。需要补充时，在输入框上方显示「补充跟品参数」和「待开始」。已识别字段进入摘要，可点「调整已填参数」重选。商品留空使用页面提示的演示商品，无法匹配本地目录时沿用样例资料并保留输入标识。

| 参数 | 当前规则 |
| --- | --- |
| 国家／语言 | 日本／日语、韩国／韩语、美国／英语。缺少可识别默认值时使用日本。 |
| 平台 | TikTok、Meta、Google、Shopee、YouTube。文本中的 Facebook 归为 Meta。缺少可识别默认值时使用 TikTok。 |
| 整套优化／视频优先 | 裂变口播、优化落地页、替换视频开头。「视频优先」是同一组执行参数，也出现在参数下拉。 |
| 保留原口播 | 沿用原口播、优化落地页、替换视频开头。 |
| 原素材快跟 | 沿用原口播、原落地页和原视频。仍生成诊断建议，可从报告单独发起落地页优化。 |
| 自定义 | 文本解析得出不同于预设的组合时保留识别结果，参数区展示「自定义」。 |

### 跟品业务规则

| 规则 | 条件 | 系统决策及产物 |
| --- | --- | --- |
| BR-08 来源商品 | 从潜在爆品进入，或输入命中本地商品 ID／名称 | 带入来源商品资料。待开始时可确认目标参数。若输入为空，采用页面提示的演示商品。未知输入保留提交标识，名称、卖点和历史素材来自演示商品，报告按样例口径标记。 |
| BR-09 目标与组合优先级 | 文本给出国家、平台及处理方式，或在待开始卡调整下拉 | 文本解析优先提取明确的目标线路。多个市场或平台无唯一解时，可回落至演示默认参数。进入补充卡后，已选下拉控制国家、平台、组合，再修改自由文本不会覆盖这些下拉值。组合中的明确「保留／沿用」或「重做／替换」可分别决定口播、落地页与视频，组合不匹配预设时显示自定义。 |
| BR-10 直接开始与补参 | 首页提交时有商品输入，且文本含受支持的国家和平台 | 符合条件时直接开始，缺一项则停在「待开始」补参，可用默认值确认。显式出现国家与平台是原型触发条件，商品链接和多国家、多平台的生产级校验待确认。 |
| BR-11 对象归属 | 跟品任务开始 | 一次确认建立独立会话与任务 ID。来源商品提供原页、口播及诊断资料。任务生成的演示克隆 ID 写入当前版落地页。ZIP 清单的商品 ID 取任务商品，目标国家与平台另存。跨线路或换商品后的真实归属见 OI-11。 |
| BR-12 任务状态 | 用户开始、暂停、继续、离开或重开任务 | 待开始尚未创建执行任务。运行中按顺序完成步骤。暂停保存剩余等待时长，继续从未完成步骤恢复。已完成步骤保留。已保存的运行中任务可在重开时接续，暂停的任务等待手动继续。 |
| BR-13 分项失败 | 落地页、口播、广告文案或视频的某个步骤抛错 | 将该分项标为失败、记录原始异常，跳过该分项未完成步骤，其他分项继续。整轮结束若仍有失败，显示对应重试入口。重试只清理选中分项的失败标记，成功步骤和人工编辑保留。 |
| BR-14 快跟与定向优化 | 选择「原素材快跟」 | 落地页可在诊断后按沿用状态就绪，问题条目标记待优化。点击「按报告优化落地页」后切换落地页处理方式，排入待处理步骤，已完成的口播和视频步骤保留。 |
| BR-15 诊断依据 | 原商品能在诊断样例中匹配，或使用了未知商品 | 匹配时使用该商品内置广告、评论与区域行为。未知商品使用模拟来源并标明参考口径。模拟点击率按点击／曝光，模拟转化率按订单／点击。报告按区域呈现点击率和停留时长，区域点击率不相加，修改效果以同条件对照验证。 |
| BR-16 落地页更新顺序 | 自动优化与人工编辑重叠，或用户撤销 | 原版快照始终用于对照。自动优化只更新命中且未手改的当前版图片字段，未命中项沿用，已改价格和图片保留。上传先验证图片与位置，成功后再回填。撤销可回退最近八步内的页面快照，恢复图、顺序、状态和价格。同市场沿用来源价格，换市场时试投价格默认待确认，人工已改价格优先。 |
| BR-17 口播与广告文案 | 沿用原口播、换目标语种、整套优化或单独改文案 | 沿用模式的中文稿取历史样例。同市场沿用时，目标语口播取原稿。跨市场沿用或整套优化时，分别取目标语言对应样例。广告标题与广告语从商品卖点和目标市场 CTA 组装。多个成片读取任务内同一份口播和文案。 |
| BR-18 口播更新与试听 | 单侧编辑原文／译文，或切换试听版本与语言 | 单侧更新提示另一侧待同步，口播版本变化会停止旧试听。可恢复上一版或重新生成成对样例。系统语音按文本、目标语种和设备音色试听，缺音色或文本时禁用。试听与文案编辑不会重写视频音轨。 |
| BR-19 成片与 BGM | 跟品成片就绪、裂变、选用或上传 BGM | 标准任务装入本地成片样例。裂变新增一个版本，沿用参考片媒体及镜头数据，可独立编辑。BGM 可用于全部或指定视频的预览，音频上传上限 30 MB，校验失败保留原选用项，实际混音导出待接入。 |
| BR-20 资产包交付 | 会话至少有一项可交付素材，用户点击下载 | 逐项读取当前版页面、成片、文案、可用音频和其他已就绪素材，同源文件读取复用，重名文件加序号。未就绪、读取失败及槽位替换映射写入清单。失败项不阻止其他素材打包。跟品交付停在下载，真实发布或投放走待确认的生产接口。 |

**业务示例。** 输入「跟品 1044535 跟到韩国 TikTok 保留原口播」，目标语种为韩语，口播按沿用规则取样例，落地页及视频仍走优化步骤。若改选「原素材快跟」，三类素材按沿用组合准备，报告仍给出可处理的问题。点击报告中的优化按钮，只重开落地页相关工作。

### 工作台与执行状态

确认后直接进入左对话、右工作区的双栏，默认「落地页」。右上角可切换「广告素材」「落地页」，非当前页签有新结果时标记更新，查看后清除。工作台还提供「视频裂变」「下载资产包」和返回首页。交付工作台左栏默认 400px，后加载样式覆盖早期百分比设置。允许手动调整，窄屏可用宽度列入验收。

| 阶段 | 可见结果与规则 |
| --- | --- |
| 克隆及获取原页 | 本地计时约 3 秒生成新商品 ID，约 7 秒获取落地页。当前版挂接新 ID，原版保留来源商品与原始快照。 |
| 核查及诊断 | 获取前两侧等待。获取后原版展示检测状态，当前版等待结果。样例标记首图和前三张详情图的四处问题，当前版仅对命中项进入优化状态。 |
| 口播与广告文案 | 准备共享口播、广告标题与广告语。多个成片共用这一份文案。 |
| 视频 | 演示片头准备、合成及成片就绪。当前内置样例为三条本地成片，可先预览，点卡片标题定位到广告素材画布继续二创。 |
| 落地页处理完成 | 默认样例有 8 张轮播主图、15 张详情图。保留未命中的原图与人工已修改内容。自动处理在当前本地实现中更新命中项的标题、文案、提示词及状态，图像像素级生成服务待接入。 |
| 进度与失败 | 整轮计时约 63 秒。对话逐步显示说明和一条当前动作，结果等对应回复显示完再呈现，图片默认预览三张、视频默认一条。已读历史可直接阅读，用户上翻时保留滚动位置。处理记录可展开，完成后自动收起。任务可暂停、继续，单项失败可重试并保留已完成内容。 |

各步骤的等待值来自本地演示计时器。

| 步骤 | 等待 | 步骤 | 等待 |
| --- | --- | --- | --- |
| 克隆 | 3 秒 | 获取原页 | 4 秒 |
| 核查 | 3 秒 | 诊断 | 7 秒 |
| 口播 | 5 秒 | 广告文案 | 4 秒 |
| 准备片头 | 8 秒 | 样例合成 | 9 秒 |
| 成片就绪 | 10 秒 | 落地页完成 | 10 秒 |

### 落地页诊断与编辑

- 「落地页诊断报告」可从左侧卡片、落地页工具栏、原版问题标记或「查看修改」进入。打开时切到「落地页」并显示右侧报告面板。从图片进入时定位并展开对应问题。从总入口进入时可浏览问题列表。关闭按钮与报告内 Escape 收起面板。
- 报告包含商品、来源与目标线路、样例广告点击率／转化率／订单、分析依据与逐项建议。逐项显示优先级、问题位置、证据、判断、具体修改、验证方式和处理状态。模拟来源明确标注。已修改条目保留「效果待验证」。
- 「定位图片」收起报告并回到对应图片。报告随进度重绘时保留同一报告的展开项、滚动和焦点。快跟可从报告点击「按报告优化落地页」。
- 原版与当前版左右对照，支持 50%、75%、100% 缩放、主图轮播和缩略图同步切换、两列同步滚动、连续详情图、「查看修改」逐项定位、撤销与本地保存状态。当前版可拖动调整图片、插入或替换图片、编辑页面价格。点图可预览。当前图片检查器提供修改、替换图片、查看原图、收藏和下载，引用图片后可在对话输入修改要求。翻译文字浮条保留于旧对比节点。原版快照用于对照。
- 当前跟品工作台交付到素材准备和导出。v1.4 的逐步审批、按卖点手动查投放视频和按线路创建预算广告草稿属于旧流程。历史会话是否仍会进入旧步骤，见 OI-11。

### 广告素材与导出

- 共享文案卡可改口播、广告语、广告标题或全部重新生成。推荐项只填入输入层，点发送才执行。切换字段保留各自草稿。可直接编辑、复制或恢复上一版。原文与译文单侧手改时会提示待同步。自然语言生成使用预置样例，明确的「改成…」可写入指定字段。
- 广告素材包含成片总览、单条视频、口播／文案和背景音乐入口。总览视频卡最多 220px 宽，媒体区高 160px，悬浮静音预览，点击进入编辑。视频操作、槽位、数据和对比规则见第 6–8 节。视频裂变使用当前可用成片作为参考，在本会话新增本地样例。
- 「下载资产包」将会话已就绪的轮播主图、详情图、成片、替换或衍生视频、口播稿、广告文案、可用音频及已选 BGM 打成 ZIP。只有系统试听时，ZIP 内提供口播稿，清单标明没有音频文件。「素材清单.json」记录文件、等待项、失败原因及镜头替换关联。单个文件读取失败仍可导出已读文件。

## 05 首页、技能与检索

### 首页与案例

首页标题为「把出单经验，做进下一条素材。」四个智能体入口依次为「全链路跟品」「视频二创」「找爆款」「爆款复刻」。点入口展开案例。悬浮案例在原文字后临时预览，移开移除预览，点击或按 Tab 才采用，重复点击同案例不重复插入。可编辑灰色占位。输入区支持文字、上传或粘贴图／视频、`/` 技能和 `@` 智能体／素材引用。Enter 发送，Shift+Enter 换行。

爆单 Hook 镜头采用独立视频胶片带，可筛选类目与平台、横向浏览、暂停或换批。悬停预览前三秒后回到开头。「潜在爆品」单独横滑和换批。广告视频库默认「最多订单」，支持优化师、时间范围、部门、语种、平台、线路和品类筛选，以及整齐排列／瀑布流切换。另有最新花费、转化成本、转化率、点击率、点击成本、点击次数及展示次数排序。卡片提供样例指标、收藏和详情入口。

### 六项技能

技能菜单与斜杠共用选择状态。一次选一项，切换保留文字和附件，删除技能标签清理任务选择。技能过程只显示流式说明。需视频的技能无指定素材时采用演示视频。缺业务参数时在对话追问。视频结果完成后保持对话，点击才在右侧打开对应视频，历史结果仍能各自打开。

| 技能 | 输入与输出 |
| --- | --- |
| 提取字幕 | 对话返回可复制文字。 |
| 配口播 | 返回可原生试听、下载的示例音频。 |
| 擦除元素 | 根据要求显示处理对象，返回视频样例。 |
| 调整画幅 | 识别 9:16、1:1、16:9。缺画幅时追问，返回对应样例。 |
| 片段生成 | 需要镜头描述。默认 9:16、8 秒，时长参数限制 3–15 秒，返回视频样例。 |
| 卖点浮层 | 缺引号中的卖点文案时追问。返回带浮层的示例视频。 |

## 06 工作区、视频与画布

- 工作区采用左对话、右画布，支持拖动分割和折叠对话。tldraw 支持移动节点、平移、缩放、适应内容和框选。普通找片可回到完整搜索结果。跟品广告素材支持回到成片总览和切换视频。

### 镜头采用、合成与交付规则

| 规则 | 条件 | 系统决策及结果 |
| --- | --- | --- |
| BR-21 搜索与采用 | 用户在整片或某槽位点击搜相似 | 整片相似只提供整片预览，候选排除自身，按商品、品类、语种、视频类型匹配数排序。槽位候选绑定发起时的槽位 ID，只有点「替换原片段」才写入采用状态，原片、其他槽位和已打开候选保留。 |
| BR-22 生成与替换 | 用户为指定槽位提交生成提示词，或选择已有结果 | 生成结果记录所属成片和槽位。用户采用后才写入当前槽位的来源、名称和状态。再次采用同一个衍生结果会提示已换上。支持上传的入口接受视频文件，本地播放引用与原片分别保留。 |

| BR-24 合成前校验 | 点击「合成成片」 | 当前成片至少一段已替换，且没有槽位本身处于生成中状态时才创建衍生成片。独立衍生卡仍在生成时，当前判断没有统一阻塞合成。同一成片已有合成结果时，当前入口提示已合成。结果在当前会话和支持的资产任务中显示。实际转码、媒体拼接和二次合成策略待接入。 |
| BR-25 爆款复刻校验 | 首页复刻已选参考片，确认人物与场景配置 | 换人物必须从人像库选人物或提交参考图，人像库最多选四位。产品与场景可提供参考图，当前对话入口的硬性校验集中在人像。共用旧表单分支还有按换项检查参考图的代码，生产统一校验见 OI-01。复刻结果在原对话中预览。 |
| BR-26 恢复与失效 | 刷新、跨端打开或中断本地上传 | 已完成的会话快照可在同一浏览器恢复。首页技能的临时视频引用失效时可回到示例素材。跟品上传按文件引用从本机恢复，未完成的编辑或上传可报中断并允许重试。分享链接要求访问侧已有对应会话快照。 |

## 08 生成、结果与切片

- 各入口按各自规则处理确认和进度。爆款复刻确认方案后启动。首页技能按输入与追问继续。跟品可暂停和分项重试。一般生成的运行态由本地定时器模拟，恢复规则见第 12 节。
- 选中视频或图片卡可在输入框回显待引用素材，确认后再输入修改要求。多条成片、切片或衍生结果可并存。带可替换结果的槽位可采用样例，合成入口按当前槽位顺序工作。
- 找片和跟品共用槽位结果卡自动避让。视频卡高度或操作面板变化时重算自动位置，移出视野的卡片保留实测尺寸，手动拖过的结果保留位置。连线持续绑定原槽位。
- 支持分段的成片可打开切片结果，按片段显示缩略、时段、状态和对应操作。可从切片回到原片画布或定位切片。无分段的技能结果保持单视频视图。
- 部分生成路径向「我的资产」写入任务状态。跟品交付由当前会话的工作台与 ZIP 承载。首页技能结果保留在技能会话中。

## 11 跨页面交互规则

1. 首页与会话共用同一输入区。预览态案例、待引用媒体和已确认引用有各自状态。提交使用已采用内容。
2. 结果默认在左侧对话可见。找片与首页技能点视频后展开对应画布，跟品在参数确认后直接打开右侧工作台。
3. 切换视频或槽位，已有结果继续挂在对应视频和槽位。卡片操作更新当前会话。处理进度不抢用户的阅读、报告焦点或已经保存的手工修改。
4. 数据面板、缩略导航、整片动作和槽位动作均按当前场景显示。验收用实际入口与视频来源作为前置条件。
5. 生产期异步沙箱、跨会话权限、探针归因、保护期和公共回流以第 16–17 节为工程依赖。

| DR-03 | 片段 | 成片切片 + 历史 AI 片段 + 预生成片段 | 搜相似与普通检索能返回切片和预生成片段 |
| DR-04 | 反推提示词 | 入库前反推，整片与槽位各一段 | 点开即可读，不现场反推 |
| DR-05 | 口播 | 入库前提取 | 整片和槽位都有文案 |
| DR-06 | 广告数据 | 投放满 15 天的成片关联数据 | 成片有订单和转化。槽位级缺失时显示「暂无」，仍可二创 |
| DR-07 | 推荐场景 | 品类 × 槽位的历史较好画面 + 偏好 | 每个试点槽位类型至少 3 个场景 |
| DR-08 | 场景提示词 | 与 DR-07 一起准备 | 每个场景一段可提交的提示词 |
| DR-09 | 提示词库 | 提示词库，条目来源待确认 | 能把短句补成可改的提示词 |
| DR-10 | 外部视频 | 平台搜索、扩词、并发、按封面标题排序截断 | 带来源、默认无槽位 |
| DR-11 | 行业参考 | 爬虫采集后按成片同一流水线加工 | 指定行业参考时能返回结果 |
| DR-12 | 商品 | 产品 ID、名称、商品图 | 输入 ID 能查到名称和图片 |
| DR-13 | 用户偏好 | 显式设置 + 探针沉淀的隐式喜好 | 按用户隔离，显式设置优先 |
| DR-14 | 用户记忆 | 对话写入 | 可改、可删 |
| DR-15 | 会话行为 | 探针实时采集曝光、打开、未打开、替换 | 实时作用于当次会话 |
| DR-16 | 个人资产 | 任务结果 | 有排队、生成中、完成、失败 |
| DR-17 | 工具结果 | 已有素材接口 | 慢任务可查询状态 |
| DR-18 | 爆单镜头 | 按类目、平台、线路和广告数据挑选 | 首页可滚动播放 |
| DR-19 | 探针日志与经验库 | 前端探针 SDK 全链路采集 | 支撑漏斗、偏好沉淀、热搜词统计 |

### 17.3 非功能需求

以下为生产验收目标。

| 编号 | 类型 | 要求 |
| --- | --- | --- |
| NFR-01 | 性能 | 内部检索目标约 500 毫秒返回首批结果 |
| NFR-02 | 性能 | 外部检索约 4–5 秒内开始有结果，先返回的来源先展示 |
| NFR-03 | 性能 | 已加工成片打开即可看到槽位，不在点击时切片 |
| NFR-04 | 异步 | 擦除、生成、合成等耗时任务异步执行。外部视频深度理解范围见 OI-03 |
| NFR-05 | 并发 | 一名用户可同时保留多个会话和多个进行中的任务 |
| NFR-06 | 容量 | 按约 500 名优化师、每人多会话估算。沙箱按会话隔离，资产按账号隔离 |
| NFR-07 | 客户端 | 无独立显卡的办公电脑可浏览和轻量裁剪。重处理不放在浏览器 |
| NFR-08 | 一致 | 点选与自然语言使用同一套槽位和同一条任务状态 |
| NFR-09 | 可恢复 | 生成中的任务刷新后仍能从资产和会话打开 |
| NFR-10 | 权限 | 个人资产保护期内仅创建者可见、可分享 |
| NFR-11 | 探针 | 非侵入采集，异步批量上报，不阻塞渲染。同时服务实时重排、长期偏好与漏斗分析 |
